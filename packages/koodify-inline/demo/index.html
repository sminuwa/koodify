Koodify

Demo for koodifyInitPayment via the koodify gateway (logs payer email / phone / name on init, merges on status). Start koodify on :8080; the demo proxies with GATEWAY_API_KEY from the repo .env.

Uses baseUrl: "/proxy/koodify" → local gateway. Checkout is gated by zainboxCode only (no public key).
