Inline checkout

Drop-in bank-transfer checkout. Call koodifyInitPayment to open a modal, show a one-time virtual account, auto-poll for payment, then return payer and optional customParam on the callback.

Prefer routing through the koodify gateway auth: "gateway" so payer + custom params are stored and re-attached on status.

Overview

  • Bank transfer only — no card UI.
  • Creates a temporary virtual account for the exact amount.
  • Listens for settlement automatically; merchant can also tap Check Payment Status.
  • Success screen stays open ~10 seconds (or until Done / close).
  • Point baseUrl at koodify. Checkout uses the publishable gateway key plus zainboxCode.

Install

Build the IIFE from packages/koodify-inline and serve dist/koodify-inline.js (or the demo copy). 

cd packages/koodify-inline
npm install
npm run build
# → dist/koodify-inline.js

Include on your page:

<script src="/path/to/koodify-inline.js"></script>

Exposes global koodifyInitPayment (and KoodifyInline.koodifyInitPayment).

Quick start

koodifyInitPayment(
  {
    amount: "500",
    txnRef: "ORDER_" + Date.now(),
    mobileNumber: "08012345678",
    zainboxCode: "YOUR_ZAINBOX_CODE",
    emailAddress: "customer@example.com",
    callBackUrl: "https://example.com/webhook",
    name: "Ada Lovelace",
    currencyCode: "NGN",
    bankType: "gtBank",
    auth: "gateway",
    baseUrl: "https://api.koodify.ng",
    customParam: {
      matric: "ND/12/2211",
      session: "2026",
      paymentType: "School Fees",
      studentId: "STU001"
    }
  },
  function (response) {
    console.log(response);
    // { status, reference, description, payer?, customParam? }
  }
  // no public key — gated by zainboxCode
);

The function also returns a Promise that resolves on success and rejects on cancel / failure.

Config fields

Field Required Notes
amount yes Naira string. Prefer whole amounts ("500").
mobileNumber yes Stored as payer.phone.
txnRef yes Unique per attempt. Used as koodify operation key.
emailAddress yes Stored as payer.email.
zainboxCode yes Merchant zainbox code.
callBackUrl yes Merchant webhook / return URL passed upstream.
name no Koodify-only. Or payer: { name }. Stripped before Zainpay.
customParam no Arbitrary object. Stored + returned. Alias: customParams.
currencyCode no Default NGN.
bankType no Default gtBank.
logoUrl no Overrides the default Koodify wordmark in the sheet header.
auth no "gateway" / "koodify" → talk to koodify (zainboxCode only).
baseUrl no Koodify origin. Production: https://api.koodify.ng.
allowRecurringPayment no Forwarded on init when set.

customParam

Pass any merchant key/value map alongside the payment. Koodify peels it off before calling Zainpay, stores it under transactions.metadata.customParam, and returns it as data.customParam on init / status — and on the browser callback. 

"customParam": {
  "matric": "ND/12/2211",
  "session": "2026",
  "paymentType": "School Fees",
  "studentId": "STU001"
}

You can also nest under metadata.customParam on raw gateway POSTs; the inline widget sends top-level customParam.

Callback response

Shape passed to the callback and Promise:

{
  "status": "success",
  "reference": "ORDER_1793402668162",
  "description": "Payment was successful",
  "payer": {
    "email": "customer@example.com",
    "phone": "08012345678",
    "name": "Ada Lovelace"
  },
  "customParam": {
    "matric": "ND/12/2211",
    "session": "2026",
    "paymentType": "School Fees",
    "studentId": "STU001"
  }
}
status When
success Transfer confirmed (auto-close or Done).
cancelled User closed / cancelled before success.
failed Init or hard failure.

Payment flow

  1. POST …/zainbox/card/initialize/payment/inline — session + store payer / customParam.
  2. GET …/zainbox/card/generate-temporary-virtual-account — one-time account for the amount.
  3. Modal shows bank details; auto-polls …/temporary-virtual-account-payment-status every ~3s.
  4. On success: confirmation UI (~10s), then callback with status / payer / customParam.

Gateway routes used

  • POST /zainbox/card/initialize/payment/inline
  • GET /zainbox/card/generate-temporary-virtual-account?bankType=&e=
  • GET /zainbox/card/temporary-virtual-account-payment-status?txnRef=

Checkout auth: active seeded zainboxCode only. Admin routes use secret GATEWAY_API_KEY. Full catalogue: docs/api.html.
