# Koodify Merchant Integration Docs

Public documentation for merchants integrating Koodify: get started, authentication (`pk_` / `sk_`), API guides, and request/response samples.

## Files
- `index.html` — page structure and content
- `styles.css` — presentation styles
- `app.js` — language tabs, copy buttons, search, scroll-spy, reading progress
- `PRODUCT.md` — product context for design work
- `assets/` — brand logos, icons, favicons, and documentation artwork

## Preview
Open `docs/developer/index.html` in a modern browser (or serve this directory statically).

## Scope
Merchant-facing only. Do not document Koodify platform secrets, admin/ops endpoints, or upstream provider internals on this site.

## Important
API paths and payloads are illustrative. Validate against the live Koodify API before production use.
