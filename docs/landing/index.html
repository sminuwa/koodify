Adaptive Bank/DVA Routing

Virtual accounts that failover when a bank lags.

Omit bankType and Koodify picks from your candidates, sticks with a winner, and retries the next bank when creation fails.

# Gateway env — omit bankType in checkout
VA_BANK_CANDIDATES=gtBank,moniepoint
VA_BANK_STICKY_SECS=600

# Optional one-shot override (no auto-switch)
bankType: "moniepoint"

Payment split

One deposit. Automatic redistribution.

Collect into a primary zainbox, then move fixed amounts and remainder shares to secondary boxes—internal, idempotent, and plan-driven.

paymentSplit: {
  shares: [
    { zainboxCode: "tutor_box", amount: "200" },
    { zainboxCode: "agent_box", amount: "50" },
    { zainboxCode: "main_box", percent: 100 }
  ]
}

Escrow

Hold funds until both sides are ready.

Collect payment into escrow, keep value locked until a release condition is met—then settle to the merchant or refund on cancel. Built for marketplaces, services, and milestone deals.

escrow: {
  mode: "hold",
  releaseOn: "merchant.confirm",
  expiresInDays: 7
}

# Later
POST /api/v1/escrow/{txnRef}/release
POST /api/v1/escrow/{txnRef}/refund
