# Koodify Logo Asset Pack

This pack contains the Koodify horizontal logo, standalone icon, transparent PNG exports,
SVG wrappers, browser favicons, and PWA/app icon sizes.

## Contents
- `logo/png/` — transparent full-logo PNGs, white-wordmark variant, and monochrome variants.
- `logo/svg/` — SVG wrappers with embedded PNG artwork (portable and visually faithful).
- `icon/png/` — standalone app mark in common sizes and monochrome variants.
- `icon/svg/` — standalone icon SVG wrapper.
- `favicon/` — browser favicon PNGs, ICO, Apple touch icon, and web manifest.
- `app-icons/` — PWA and high-resolution app icon exports.

## Usage
- Use `logo/png/koodify-logo-original-transparent.png` on light backgrounds.
- Use `logo/png/koodify-logo-white-wordmark-transparent.png` on dark backgrounds.
- Use `icon/png/koodify-icon-*.png` for app icons, avatars, and compact placements.
- Use `favicon/favicon.ico` and `favicon/site.webmanifest` for websites.

## Notes
The SVG files preserve the supplied logo artwork by embedding transparent PNG data.
They are scalable containers, but the embedded artwork itself is raster-based.
For a fully editable vector logo, the mark and wordmark should be redrawn as vector paths
in a design tool using the original brand artwork as reference.
