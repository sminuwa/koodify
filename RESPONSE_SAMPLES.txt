Koodify API — response samples
========================================================================

Canonical envelope for every JSON endpoint:

{
  "code": "00",
  "status": "200 OK",
  "description": "successful",
  "data": {
    "/* resource fields */": "..."
  }
}

Rules:
- Always: code, status, description, then data.
- Object resources: data is an object (e.g. data.accountNumber).
- List resources: data is an array.
- zainboxCode is never returned to merchants.
- Envelope status is an HTTP-ish string (e.g. "200 OK"); a boolean
  result inside the payload lives at data.status and does not replace it.
- Treat payment success from data.paymentStatus / data.koodify.isPaid,
  not from code alone.

Samples below are illustrative successful shapes for the stable /api/v1
surface. Field sets can vary slightly by upstream; the envelope does not.
